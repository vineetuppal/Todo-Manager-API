# Todo Manager API

A simple and efficient backend API for managing Todo tasks. This project is built with Node.js, Express, and MongoDB, providing a RESTful interface for creating, retrieving, updating, and deleting Todo items.

## Features

- **Create Todo**: Add a new task with a title and description.
- **Get All Todos**: Retrieve a list of all tasks.
- **Get Todo by ID**: Fetch a specific task using its unique ID.
- **Update Todo**: Modify the details of an existing task.
- **Delete Todo**: Remove a task from the database.

## Technologies Used

- **Node.js**: JavaScript runtime for building the server.
- **Express**: Web framework for creating the API routes.
- **MongoDB**: NoSQL database for storing Todo data.
- **Mongoose**: ODM library for MongoDB.
